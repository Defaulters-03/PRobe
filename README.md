# PRobe
Triage GitHub pull requests in seconds.

Maintainers get buried in low-effort PRs, especially in October. PRobe scans a repo's open pull requests and labels each one as spam, low-effort, or legit, with a confidence score and the exact signals behind the verdict. It's a triage assistant: it suggests, and the maintainer decides.

Built with Gemma 4 (open-weight) via the Gemini API. MIT licensed.
